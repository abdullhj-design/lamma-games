# ديوانية الألعاب — لمّة سمول فاميلي

موقع ألعاب جماعية للجَمعات: شاشة للمقدّم على البروجكتر، وجوالات للاعبين ولجنة التقييم.
يشتغل على GitHub Pages، والربط بين الأجهزة عن طريق Firebase Realtime Database.

## الملفات

| الملف | وش فيه |
|---|---|
| `index.html` | الموقع كامل: الألعاب والفعالية ولجنة التقييم ولوحة الإدارة |
| `lamma-firebase.js` | يربط الموقع بـ Firebase: الدخول، ونقل الجرس والأصوات بين الأجهزة، وحفظ المحتوى |
| `config.js` | إعدادات Firebase وإيميل صاحب الموقع — **الملف الوحيد اللي تعدّله يدوياً** |
| `content.json` | محتوى افتراضي عام (الألعاب وفعالية تحديات سعودية) يُستخدم لين تحفظ من لوحة الإدارة |
| `database.rules.json` | قواعد الحماية لقاعدة البيانات — تنلصق في Firebase |
| `media/` | صور فعالية تحديات سعودية |

محتوى العائلة (اللجان والأعضاء والرموز) **ما ينحفظ في المستودع**، ينحفظ في Firebase بس.

## الإعداد لأول مرة

1. عبّ `config.js` بإعدادات Firebase وإيميلك.
2. في Firebase ← Realtime Database ← Rules: الصق محتوى `database.rules.json` بعد ما تبدّل `PUT_ADMIN_GMAIL_HERE` بإيميلك، واضغط Publish.
3. في Firebase ← Realtime Database ← Data ← ⋮ ← Import JSON: ارفع ملف المحتوى الخاص (`lamma-seed-private.json`) اللي أرسلته لك.
4. ارفع الملفات للمستودع، وفي GitHub ← Settings ← Pages اختر الفرع `main` والمجلد `/ (root)`.
5. افتح الموقع، اضغط «دخول صاحب الموقع» تحت، وادخل بحساب Google.
6. من «إدارة الموقع» حدّد **الرقم السري للمقدّم** من جديد واحفظ.

## التعديل بعدين

- **محتوى** (كلمات، أسئلة، لجان، نصوص، رموز): من لوحة الإدارة داخل الموقع. ما يحتاج Git.
- **ميزات وألعاب جديدة**: تعديل في `index.html` ثم:

```
git add .
git commit -m "وصف التعديل"
git push
```

GitHub Pages يحدّث الموقع خلال دقيقة تقريباً.
